## 2025-02-27 - [ControlPanel UX and Accessibility Improvements]
**Learning:** Adding a `title` to a disabled button requires wrapping the button in another element (like a `span` or `div`), and ensuring `pointerEvents: "none"` is set on the button when it's disabled. This is required because disabled buttons don't fire or bubble mouse events natively, preventing the wrapper from triggering its hover state and showing the title/tooltip. Adding `<label>` helps Screen Reader users contextually understand what a `select` element does. Also setting `pointerEvents: "auto"` when the button is enabled ensures normal mouse functionality. Improved WCAG compliance for Stop button color contrast over its active background state. Using `<animateTransform>` in SVG enables lightweight spinners without requiring external CSS for animation.
**Action:** When creating tooltips for disabled buttons in React/Preact, always wrap the button and manually manage `pointer-events: "none"` on the disabled state. Continue prioritizing accessible `<label>` elements for forms where space permits and check dynamic background color changes for appropriate text contrast. Use inline SVGs with `animateTransform` for independent spinners.
